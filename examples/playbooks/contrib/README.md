# Contributed playbooks

FortiSOAR playbook YAMLs from other projects: use-case demos, compiler examples,
repro playbooks and framework collections. They are real-world playbooks, not
library examples, and many expect connectors or records that a fresh box won't
have.

| Directory | Count | Contents |
|-----------|-------|----------|
| `fsrpb/` | 32 | fsr-playbook-framework examples: step-type demos, recipes, tests and the all-step-types capstone |
| `uc/` | 13 | Use cases: phishing, triage, endpoint isolation, blocking, cloud containment, patching and more |
| `demos/` | 6 | Demo playbooks (FortiEDR, FortiSOC, vulnerability management) |
| `fortisoar/` | 8 | Standalone playbooks, repros and research |
| `ztpf2/` | 17 | ZTPF2 collections: buttons, triggers, functions, proxy API, upgrade checks |

These are copies. The archetype pilot playbooks live in `scripts/`.
