.. py:class:: APIKeyAuth(base_url: str, api_key: str, verify_ssl: bool = True)

   Bases: :py:obj:`pyfsr.auth.base.BaseAuth`


   API Key authentication handler for FortiSOAR.

   API key authentication has several limitations:

   - Cannot use /auth endpoints
   - Cannot export configurations
   - Cannot call the /api/3/bulkupsert|insert|update|delete/* routes directly
     (product bug on 8.0.0/8.0.1) -- but the client no longer fails on them: it
     transparently decomposes each batch into the single-record routes the key
     CAN use (``FortiSOAR._bulk_via_single_routes``), so ``bulk_upsert`` and
     friends work under an API key.
   - Cannot reach the built-in (``FSR``-auth) MCP servers: fsr-ai replays the caller's JWT to them
     (``BaseAuth.OPERATION_FORWARDED_BEARER``)

   Methods that need a JWT are marked with ``pyfsr.auth.guards.requires_jwt``, which raises
   ``UnsupportedAuthOperationError`` before any request is sent.

   :param base_url: Base URL of the FortiSOAR instance
   :param api_key: The FortiSOAR API key
   :param verify_ssl: Whether to verify SSL certificates. Defaults to True.

   :raises APIError: If API key validation fails

   .. rubric:: Example

   >>> auth = APIKeyAuth(
   ...     base_url="https://fortisoar.example.com",
   ...     api_key="your-api-key"
   ... )
   >>> headers = auth.get_auth_headers()
